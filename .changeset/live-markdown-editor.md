The content editor is now a single live-preview editor instead of separate Write and Preview tabs. Headings, bold, italic, strikethrough, inline code, links, quotes, lists, checkboxes, rules, images/videos and `[[node]]` links render as you type, and their markdown syntax only shows on the line you're editing. Checkboxes toggle on click, node links select the node, and Ctrl/Cmd+click opens web links in your browser. Files are never reformatted.
