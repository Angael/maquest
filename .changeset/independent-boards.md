Boards are now independent canvases. No board is special: each shows only the cards placed on it, any board can be deleted while another remains, and new cards land only on the board they were created on. Delete removes a card from the current board without deleting it (Shift+Delete deletes it everywhere). Copy/paste now places a reference to the same entity instead of copying it, and a new right-click card menu offers Copy reference, Duplicate (Ctrl+D, a real copy), Group, Remove from board and Delete everywhere. Existing projects keep every node on their main board. Agents can choose a board when creating nodes.
